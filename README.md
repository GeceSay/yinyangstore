# ☯ YinYang Store

FiveM Scriptleri, Discord Botları ve Web Sistemleri için modern, şık ve Yin-Yang (siyah/beyaz/antrasit) temalı vitrin mağazası.

Bu proje **tamamen statik (pure client-side)** olarak hazırlanmıştır; harici bir Node.js veya veritabanı sunucusu gerektirmez. Doğrudan **GitHub Pages** üzerinde ücretsiz ve 7/24 kesintisiz çalışır.

---

## 🚀 GitHub Pages ile Yayına Alma (2 Dakika)

1. Bu klasördeki dosyaları (`index.html`, `style.css`, `app.js`, `README.md`) bir GitHub reposuna yükleyin (push veya web arayüzünden sürükleyip bırakarak).
2. GitHub'da reponuzun **Settings** (Ayarlar) sekmesine gidin.
3. Sol menüden **Pages** seçeneğine tıklayın.
4. **Build and deployment** başlığı altında:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` (veya `master`) / `/(root)` seçin.
5. **Save** butonuna tıklayın.
6. Yaklaşık 30-60 saniye sonra siteniz `https://kullaniciadi.github.io/reponame/` adresinde canlıya geçecektir!
